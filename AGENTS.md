# Project notes (ai-notes)

- Working notes live in `ai-notes/` (symlink into the private
  ai-project-notes repo; never tracked by this clone's git).
- Session start: read `ai-notes/README.md`, the «Итог» of the active
  report and «Текущий шаг» in `ai-notes/t1-work-plan.md`; the workflow
  rules are in `ai-notes/../../REPORTING-WORKFLOW.md`.
- After a meaningful step: add a dated «Сделано / Выводы / Дальше»
  entry to the active report, update its «Итог» and the plan/index.
- Never `git add`/`commit`/`push` inside ai-notes, never touch sibling
  projects or global settings, never push anything to GitHub.
- The old pCloud contour (`pclaude/`) is closed: edit notes only via
  `ai-notes`.
