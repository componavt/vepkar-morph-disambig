# vepkar-morph-disambig

В этом репозитории исследуется ранжирование кандидатных морфологических
разборов слов в контексте корпуса VepKar: если для словоформы получено одно
или несколько возможных разборов, задача — ранжировать их с опорой на
корпусные данные.

Репозиторий будет содержать реализации владельца всех трёх направлений
исследования:

- `src/core/` — код, общий для трёх направлений.
- `src/t1_features/` — ранжирование морфологических кандидатов на основе
  признаков.
- `src/t2_context/` — методы, использующие контекст.
- `src/t3_transfer/` — эксперименты по переносу (transfer).

## Статус

Это начальный каркас: точка входа командной строки и структура каталогов.
Загрузка данных, валидация, модели и оценка ещё не реализованы.

## Данные

Корпусные данные позднее будут получены отдельно из `dictorpus-data` и
в этот репозиторий не попадут; `data/dictorpus-data/` исключён из Git.
Общие производные входные данные будут лежать в `data/derived/`.
