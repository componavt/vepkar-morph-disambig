The files were generated by `compare-t1-runs`, copied from
`work/comparisons/v2026.11/`, and compressed as `.csv.zst`.
Each file compares all 2,613 dev word occurrences.

The filename specifies the A/B order; deltas are computed as B − A.
The net increase in correct Top-1 predictions equals corrected − regressed:

```text
C=0.1 ── +88  ──> C=1
C=1   ── +20  ──> C=10
C=0.1 ── +108 ──> C=10
```

C=10 has the highest Top-1 and MRR among the three settings evaluated on this
dev set; its Top-3 equals that of C=1. This is not a final test evaluation. These
results cannot be compared directly with `v2026.09`: the words and the split differ.
