# Частотный базовый метод

Исходные данные: `dictorpus-data`, версия `v2026.11`.
Разбиение: `data/derived/splits_v2026.11.csv`.

`dev.csv.zst` содержит предсказания на `dev`. На `test` метод для этой версии не запускался.

## Метод

`score` — число экспертных выборов пары `(wordform_id, gramset)` в части `train`.
Пара без таких выборов получает `score = 0`.
