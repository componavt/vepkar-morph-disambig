# G1: T1.1 и частотный базовый метод

Первая контрольная точка исследования на `dictorpus-data` v2026.11 с опубликованным разбиением по текстам. Настройка T1.1 выбрана на `dev` из заранее согласованной сетки `C = 0.1, 0.3, 1, 3, 7, 10, 13, 30, 42, 100`: критерий выбора — наибольшая наблюдаемая Top-1; MRR и Top-3 — дополнительные метрики. Выбрано `C=10`.

Интервалы неопределённости рассчитаны по 1000 bootstrap-выборкам целых групп `(language, text_id)` с возвращением; использован процентильный 95-процентный интервал и seed `20261109`. Часть `test` оценена по одному разу для T1.1 и частотного базового метода, после фиксации C.

| Метрика test | Частотный базовый метод | T1.1, C=10 | Парная разница T1.1 − baseline (95% ДИ) |
| --- | ---: | ---: | ---: |
| Top-1 accuracy | 0.6874 | 0.8480 | +0.1606 (+0.1330, +0.1963) |
| MRR | 0.8352 | 0.9204 | +0.0852 (+0.0705, +0.1042) |
| Top-3 accuracy | 0.9906 | 0.9976 | +0.0071 (+0.0034, +0.0114) |

Парный bootstrap-интервал разницы Top-1 выше нуля. Языковые и одобренные диагностические срезы приведены в `slices.csv`; наиболее частые грамматические путаницы T1.1 — в `top-confusions.csv`. Также приложены сводка сетки C и запись выбора.

## Файлы

- `test-comparison.json` — общие результаты test и парные bootstrap-интервалы.
- `dev-grid-summary.json` — результаты десяти C на dev и парные интервалы разниц соседних C.
- `dev-grid.csv` — компактная таблица dev-метрик, доверительных интервалов и разниц Top-1 соседних C.
- `selection.json` — критерий выбора C на dev, записанный до test.
- `slices.csv` — Top-1, MRR, Top-3 и текстовые bootstrap-интервалы Top-1 по языку, знакомству пары/слова, числу кандидатов и группе NOM/ACC/GEN.
- `top-confusions.csv` — 20 самых частых пар «золотой gramset → gramset кандидата Top-1» среди ошибок Top-1 T1.1.
- `t1.1-test.csv.zst` и `frequency-baseline-test.csv.zst` — полные проверенные предсказания на test.

Контрольная точка относится к строгому benchmark с одним экспертным gold-разбором на словоупотребление. В неё не входят абляции, частотный вариант T1.2, ручная классификация ошибок и проверка опубликованных правил словоизменения. Сетка C выбиралась по dev; приведённые интервалы точечные и не корректируются за перебор десяти настроек. Test — финальная оценка этой контрольной точки; его нельзя использовать для подстройки следующих моделей.
