# Сохранённые результаты

Здесь хранятся результаты, вручную принятые как исходные точки
или значимые результаты сравнения методов.

Результаты сгруппированы по версии исходных данных.

Каждый результат хранится в отдельной папке `<tag>/<run_id>/`.

В комплект входят описание результата и предсказания для оцениваемой
части данных:

- `README.md` или `README.ru.md` — условия эксперимента, число
  словоупотреблений и строк кандидатов, метрики;
- `dev.csv.zst` — предсказания для `dev` (для частотного метода необязателен);
- `test.csv.zst` — предсказания для `test`, если выполнена итоговая оценка;
- `metrics.json` — настройки, сведения об исходных данных и метрики
  без округления, если файл сформирован командой оценки.

Экспорт T1.1 создаёт `README.md`, `metrics.json` и `dev.csv.zst`.
Модель и локальный паспорт запуска в экспортируемый комплект не входят.

Рядом можно сохранять производную диагностическую таблицу,
например `dev-diagnostics.csv.zst`. Она не заменяет predictions;
её назначение и источник указывают в README результата.

Имя папки результата имеет вид:

```text
YYYY-MM-DD__author__task__method
```

Обозначения `task`: `core`, `t1-features`, `t2-context`, `t3-transfer`.

Перед принятием предсказания проверяют и оценивают.
Для проверки сжатый CSV предварительно распаковывают.
Создание файла и успешная проверка сами по себе
не делают результат принятым.

Ранее принятые предсказания не перезаписывают.
Новый принятый вариант метода сохраняют в отдельной папке.

## Сжатие CSV

Пример команды для максимального сжатия (`csv` -> `zstd`):

```bash
zstd --ultra -22 file.csv
```
