# Saved results

This directory stores selected control and final experimental results.

Results are grouped by source-data version.

Each result is stored in a separate directory, `<tag>/<run_id>/`.

The package contains a result description and predictions for the
evaluated data split:

- `README.md` or `README.ru.md` — experiment settings,
  word-occurrence and candidate-row counts, and metrics;
- `dev.csv.zst` — predictions for `dev`
  (optional for the frequency baseline);
- `test.csv.zst` — predictions for `test`, if final evaluation
  has been performed;
- `metrics.json` — settings, source-data information, and unrounded
  metrics, if generated by the evaluation command.

T1.1 export creates `README.md`, `metrics.json`, and `dev.csv.zst`.
The model and local run passport are not included in the exported package.

A derived diagnostic table, such as `dev-diagnostics.csv.zst`,
may be stored alongside the predictions. It does not replace them;
its purpose and source are documented in the result README.

Automatically created T1 run directories follow this naming scheme:

```text
<method>-C<value>-<YYYY-MM-DD>[letter]
```

For example, `t1.1-C1-2026-10-29` is a T1.1 run with C=1,
prepared on 29 October 2026.

For the same method, C, and date, the first directory has no letter.
Starting with the second run, a lowercase Latin letter from `b` to `z`
is appended directly to the date. The letter `a` is not used:

```text
t1.1-C1-2026-10-29     — first run
t1.1-C1-2026-10-29b    — second run
t1.1-C1-2026-10-29c    — third run
```

Square brackets indicate an optional part of the name and are not
included in the directory name.

Export preserves the run directory name.
The date in the name refers to run preparation, not export.

To save a T1.1 result, use the
[export command](../../README.md#exporting-a-result).

Previously accepted predictions are not overwritten.
A newly accepted method variant is stored in a separate directory.

## CSV compression

Example command for maximum compression (`csv` -> `zstd`):

```bash
zstd --ultra -22 file.csv
```
