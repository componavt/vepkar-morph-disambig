# Частотный базовый метод

Исходные данные: `dictorpus-data`, версия `v2026.09`.

`test.csv.zst` содержит предсказания для итоговой оценки.
`dev.csv.zst` — материал для диагностики частотного метода.

## Метод

`score` — число экспертных выборов пары `(wordform_id, gramset)` в обучающей части `train`. 
Если пару ни разу не выбирали, частота := 0 (пара с нулевой частотой, unseen).

Кандидаты упорядочиваются:
1. По убыванию `score`.
2. При равенстве частот — по возрастанию `wordform_id`.
3. При равенстве частот и `wordform_id` — по `gramset`
   в лексикографическом порядке.
