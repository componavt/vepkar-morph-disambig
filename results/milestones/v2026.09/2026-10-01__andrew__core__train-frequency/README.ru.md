# Частотный базовый метод

Исходные данные: `dictorpus-data`, версия `v2026.09`.

`test.csv.zst` содержит предсказания для итоговой оценки.
`dev.csv.zst` — материал для диагностики частотного метода.


Частоты считаются по gold-разборам train.
Ключ: (wordform_id, gramset).
Score — частота этой пары; unseen пары (с нулевой частотой) получают 0.

Сортировка:
score по убыванию,
`wordform_id` по возрастанию,
gramset в лексикографическом порядке.
