# Очередь на ручную проверку

Файлы `zero_word_number_sentences_<tag>.csv` содержат список предложений для ручной
проверки. Каждое предложение включено в очередь, потому что в нём обнаружена
хотя бы одна запись слова с `word_number=0`.

Столбцы CSV:

```csv
language,sentence_id
```

Каждая строка идентифицирует предложение; его текст и XML в CSV не записаны.

Условный пример XML предложения с элементом `<w id="0">` (нулевой ID):

```xml
<s id="1"><w id="1">Этот</w> <w id="0">кот</w> <w id="2">спит</w>.</s>
```

Это упрощённая иллюстрация, а не реальное предложение корпуса. При проверке
нужно сопоставить запись слова с XML предложения: само включение в очередь
ещё не объясняет причину `word_number=0`.

Эти списки предназначены для ручной проверки, а не для обучения
или оценки моделей.
