# Очередь на ручную проверку

Файлы `zero_word_number_sentences_<tag>.csv` содержат список предложений для ручной
проверки. Каждое предложение включено в очередь, потому что в нём обнаружена
хотя бы одна запись слова с `word_number=0`.

Столбцы CSV:

```csv
language,sentence_id
```

Каждая строка идентифицирует предложение; его текст и XML в CSV не записаны.

Условный пример: у записи слова «кот» указана нулевая позиция
`word_number=0`.

Строки таблицы `words`:

```csv
word_id,sentence_id,word_number,word
101,10,1,этот
102,10,0,кот
103,10,3,спит
```

XML того же предложения:

```xml
<s id="1"><w id="41">Этот</w> <w id="42">кот</w> <w id="43">спит</w>.</s>
```

В очередь включается предложение `sentence_id=10`, потому что одна
из его записей слов имеет `word_number=0`. Значения `word_id`
и атрибута `id` элемента `<w>` при этом положительные.

`word_number` — позиция слова в корпусной таблице, а `id` элемента
`<w>` — его XML-идентификатор. Критерий включения в очередь —
нулевой `word_number`, а не нулевой атрибут `id` в XML.

Пример условный, не из корпуса. Для выяснения причины нулевой
позиции нужно сопоставить записи слов с исходным XML предложения;
само включение в очередь причину не устанавливает.

Эти списки предназначены для ручной проверки, а не для обучения
или оценки моделей.
