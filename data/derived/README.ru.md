# Производные данные

Здесь хранятся производные данные из
[dictorpus-data](https://github.com/componavt/dictorpus-data/).
Версия исходных данных обозначена в имени файла.
Исходные выгрузки здесь не хранятся.

## Строгий набор для оценки

В набор включают словоупотребления с не менее чем двумя различными
кандидатами `(wordform_id, gramset)` и ровно одним экспертным выбором
(`relevance = 2`). Повторные кандидатные записи недопустимы;
`gramset` каждого кандидата должен быть непустым.

Словоупотребление, его предложение и текст должны однозначно
определяться исходными идентификаторами. Всё предложение исключают,
если у любого его слова позиция `word_number` равна нулю
или положительные позиции повторяются.

При непригодности кандидата исключают словоупотребление целиком,
а не сокращают его список альтернатив. Исходные данные не изменяют.

## Разбиение train/dev/test

Файл `splits_<tag>.csv` создаёт команда:

```bash
python src/cli.py make-splits
```

Например, `splits_v2026.09.csv` относится к исходным данным
`dictorpus-data` версии `v2026.09`.

Файл содержит три столбца:

| Столбец | Значение |
|---|---|
| `language` | `vep`, `krl`, `olo` или `lud` |
| `text_id` | идентификатор текста в соответствующей корпусной выгрузке |
| `split` | `train`, `dev` или `test` |

Одна строка назначает **целый текст** одной из частей —
`train`, `dev` или `test`. Все пригодные словоупотребления этого
текста получают ту же часть, что и их текст; связь устанавливается
по паре `(language, text_id)`.

Для каждого подкорпуса целевые доли составляют
80% / 10% / 10% по числу строк кандидатов. Доли по числу текстов
и словоупотреблений могут отличаться: тексты назначаются целиком (текст нельзя разрезать между частями).

- `train` — обучение модели;
- `dev` — выбор её настроек и варианта;
- `test` — итоговая оценка после выбора.

Для сравнения методов используйте один и тот же файл разбиения.

При создании файла команда сообщает `created`. Если существующий
файл имеет то же содержимое, сообщает `unchanged` и не перезаписывает
его. Другое содержимое существующего файла приводит к отказу.
