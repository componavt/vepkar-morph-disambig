# Derived data

This directory contains data derived from the version of
[dictorpus-data](https://github.com/componavt/dictorpus-data/)
identified in each filename. The source exports are not stored here.

## Train/dev/test split

The `splits_<tag>.csv` file is generated by:

```bash
python src/cli.py make-splits
```

For example, `splits_v2026.09.csv` corresponds to version `v2026.09` of
`dictorpus-data`.

The file has three columns:

| Column | Meaning |
|---|---|
| `language` | `vep`, `krl`, `olo`, or `lud` |
| `text_id` | Identifier of a text in the corresponding corpus export |
| `split` | `train`, `dev`, or `test` |

Each row assigns an **entire text** to one split. All eligible word occurrences
in that text inherit its assignment through the `(language, text_id)` pair.

The target for each language variety is approximately 80% / 10% / 10% by the
number of candidates in eligible instances. The proportions by number of
texts or word occurrences may differ because a text cannot be split across
parts.

- `train` — train a model;
- `dev` — select its settings and variant;
- `test` — evaluate it after selection.

Use the same split file when comparing methods. The command does not
automatically replace an existing file with different content.
